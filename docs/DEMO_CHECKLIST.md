# 졸업전시 데모 체크리스트

전시 시연은 **Android APK**로 진행한다. 위급 자동 알림 같은 핵심 기능이 앱에서만 동작하기 때문이다. 웹 배포는 필수가 아니다.

## 1. 빌드 전 준비

- [ ] 최신 `soh2` 브랜치를 받는다.
- [ ] 빌드할 컴퓨터에서 `npm ci`를 실행한다.
- [ ] `.env`를 채운다. `EXPO_PUBLIC_REALESTATE_API_KEY`와 `EXPO_PUBLIC_JUSO_API_KEY`가 없으면 전세가율 조회와 건물 확인이 꺼진다.
- [ ] `.env`의 Gemini 키를 전시용 새 키로 바꾼다.
- [ ] `npm run check`를 통과시킨다.
- [ ] 앱 owner 계정(`hdeid`)으로 `eas build --platform android --profile preview`를 실행한다.

`.env`를 바꾼 뒤에는 반드시 다시 빌드한다.

## 2. 시연 계정과 데이터

- [ ] 일반 사용자 계정을 만든다. **가입 이름을 기억해 둔다.** 보고서 서명 때 똑같이 입력해야 한다.
- [ ] 보호자 계정을 만들고 서로 연결한다. 위급 알림 시연에는 폰 2대가 필요하다.
- [ ] 사건을 미리 만들어 둔다. 사진, 음성, 메모, 계약서 분석 증거를 넣는다.
- [ ] 실제 개인정보와 실제 피해 사례는 입력하지 않는다.
- [ ] 관리자 기능을 시연한다면 관리자 계정을 확인한다.

실거래 예시 데이터는 **도봉구 + 전월세 분석** 조건에서 표시된다. 실거래가 API가 실패해도 이 지역은 "예시" 표시와 함께 나온다.

피해자 연대방의 대화와 핫게시판 댓글은 앱에 들어 있는 시연용 더미 데이터다.

## 3. 폰에서 전체 기능 확인

시연할 폰에 설치한 APK로 직접 확인한다.

- [ ] 회원가입, 로그아웃 후 다시 로그인
- [ ] 계약 전 체크리스트: 단계 표시, 설명 펼치기, 체크 후 다시 들어와도 유지
- [ ] 계약서 촬영과 AI 분석, 위험 조항과 협상 문구 표시
- [ ] 전세가율 조회, 건물 확인
- [ ] 사진 업로드: 워터마크, GPS, 글자 인식
- [ ] 음성 녹음과 텍스트 변환
- [ ] 영상 업로드와 5초 지점 썸네일
- [ ] 타임라인과 대응 퀘스트, Themis AI 질문
- [ ] 보고서 서명 후 PDF 저장, **파일을 열어 사진과 서명 정보 확인**
- [ ] 서명 후 증거를 추가하면 다시 서명을 요구하는지 확인
- [ ] 위급 자동 알림: 보호자 폰에 알림 도착
- [ ] 게시판과 피해자 채팅

## 4. 전시 당일

- [ ] 데이터가 넉넉한 휴대폰 핫스팟을 준비한다. 전시장 와이파이만 믿지 않는다.
- [ ] 폰 2대와 보조 배터리를 준비한다. 앱은 미리 로그인해 둔다.
- [ ] 위치, 카메라, 마이크, 알림 권한을 허용해 둔다.
- [ ] 시연 전 Gemini 호출이 되는지 계약서 분석을 한 번 돌려 본다.
- [ ] **시연 영상을 미리 녹화해 둔다.** 네트워크나 사용 한도 문제가 생기면 영상으로 대체한다.
- [ ] 위급 알림은 전시 전에 알림이 오는 시간을 재 두고, 무응답 시간은 가장 짧게 설정한다.

## 5. 전시 후

- [ ] 전시용 Gemini 키를 삭제한다.
- [ ] 시연 계정과 데이터를 정리한다.
- [ ] 실제 출시를 진행한다면 `RELEASE.md`를 따른다. 약관의 운영 주체, 문의처, 보관 기간과 서명 보안 규칙 배포도 그때 처리한다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| AI 기능이 모두 실패 | 인터넷 연결, Gemini 키, 사용 한도 |
| 전세가율이나 건물 확인이 안 됨 | 빌드에 키가 들어갔는지 확인, 전세가율은 도봉구 예시로 시연 |
| 키를 바꿨는데 그대로 | APK를 다시 빌드했는지 확인 |
| 서명 버튼이 안 눌림 | 입력한 이름이 가입 이름과 같은지, 동의에 체크했는지 확인 |
| 위급 알림이 안 옴 | 보호자 연결 수락, 알림 권한, 네트워크 확인 |
